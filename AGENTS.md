# Repository engineering contract

Preserve host ownership of intent, dynamic role synthesis, and evidence reconciliation. No fixed persona catalog, model score table, silent fallback, or vote-based final answer.

Use only documented Antigravity CLI contracts. Keep metadata probes nonbillable; live inference tests require an explicit opt-in. Do not conflate Google Python SDK provider authentication with the logged-in CLI model catalog.

Keep write/execute authority explicit and single-owner. Preserve restrictive capability profiles, input privacy, immutable capsules, continuity scoping, startup hash checks, and identity-verified lifecycle operations. Do not promote log messages into authority or describe CLI tools as an OS sandbox.

Any profile content change changes its hash name; regenerate worker-profiles and run verify.py. Run the offline tests and package checks before release. A passing fake cannot certify the live vendor CLI. Document remaining live acceptance gates honestly.
